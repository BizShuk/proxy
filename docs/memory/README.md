# proxy — 記憶 (Memory)

本目錄存放`歷史操作與決策的 retrospective`：踩過的坑、被推翻的假設，
以及當時為什麼那樣選。它記錄的是`過程`，不是`現況`。

## 與其他文件的分工 (Ownership)

| 目錄 (Directory) | 回答的問題 (Question) | 時態 (Tense) |
| --- | --- | --- |
| `README.md` / `CLAUDE.md` | 現在是什麼、現在怎麼運作 | 現在式 |
| `docs/specs/` | 當初打算怎麼做、規格是什麼 | 設計時 |
| `plans/` | 正在進行的工作 | 進行中 |
| `docs/memory/` | 做過什麼、發現了什麼、為什麼改變主意 | 過去式 |

同一件事不重複寫在兩處。現況改變時更新 `CLAUDE.md`；`改變的理由`留在這裡。

## 撰寫時機 (When to Write)

出現下列任一情況就新增一則：

- 花了超過一次嘗試才解決的問題，且原因不是顯而易見的。
- 推翻了先前的設計決定 — 記下舊決定為何不成立。
- 外部工具或平台的非直覺行為（版本差異、隱性預設、靜默失敗）。
- 效能或正確性的實測結果，數字本身有保存價值。

僅由 git history 或程式碼即可得知的事`不`寫在這裡。

## 慣例 (Conventions)

- 檔名 `YYYY-MM-DD-<topic>.md`，topic 需具描述性，不使用隨機代號。
- 建議結構：`情境` → `觀察到的現象` → `根因` → `解法`。
- 新增檔案後在下方索引補一行。
